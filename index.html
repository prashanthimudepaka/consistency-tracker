☁ Sync across devices

Your data is stored in a private Gist in your own GitHub account — nothing is sent anywhere else.

  1. On github.com open Settings → Developer settings → Personal access tokens → Tokens (classic) and choose Generate new token (classic).
  2. Tick the gist checkbox — that one scope is all this needs. Fine-grained tokens do not work: GitHub's Gists API only accepts classic tokens.
  3. Copy the token (it starts ghp_) and paste it below — on this device and on your phone.
